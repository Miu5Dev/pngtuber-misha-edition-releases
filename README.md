# PNG TUBER MISHA EDITION

Descargas del programa (solo ejecutables). Para Windows 10/11.

**Instalar:** ve a **Releases**, baja `PNGTuber-Misha-Edition-Setup.exe` y ábrelo. No necesita ser administrador; crea accesos
directos y aparece en «Aplicaciones instaladas».

**Sin instalar:** baja `pngtuber-rs-windows.zip` (o `pngtuber-rs.exe` y `SpoutLibrary.dll`), déjalos en la misma carpeta y abre `pngtuber-rs.exe`.

El programa se actualiza solo: busca versiones nuevas en este repositorio al abrirse y cada 6 horas (se puede desactivar en Ajustes).

Lee avatares `.save` del PNGTuber Plus original, envía a OBS por Spout, tiene alertas por fuente de navegador y conexión con Twitch.
