# PNG TUBER MISHA EDITION

Descargas del programa (solo ejecutables). Para Windows 10/11.

1. Ve a **Releases** y baja `pngtuber-rs-windows.zip` (o `pngtuber-rs.exe` y `SpoutLibrary.dll` sueltos).
2. Deja los dos archivos en la misma carpeta y abre `pngtuber-rs.exe`.

El programa se actualiza solo: busca versiones nuevas en este repositorio al abrirse y cada 6 horas
(se puede desactivar en Ajustes).

Lee avatares `.save` del PNGTuber Plus original, envía a OBS por Spout, tiene alertas por fuente de
navegador y conexión con Twitch.
